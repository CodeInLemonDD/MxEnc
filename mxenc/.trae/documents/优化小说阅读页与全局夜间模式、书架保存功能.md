## 问题与目标

* 小说阅读页缺少“保存到书架”入口，顶栏未显示返回与标题。

* 夜间模式在设置页未生效，需要全局主题切换与持久化。

* 保持底部左侧固定低对比度水印；不使用动态水印层。

## 小说阅读页优化

* 顶栏：在 `lib/screens/novel_reader_screen.dart` 添加 `AppBar`，包含：

  * 返回按钮（`Navigator.pop`）

  * 标题（小说名称，副标题作者）

  * 操作按钮：“保存到书架”

* 参数扩展：`NovelReaderScreen` 增加可选 `sourceFilePath`（原 `.mxenc` 文件路径）与 `coverBytes`（封面字节）用于保存索引。

* 保存逻辑：调用 `StorageService.saveShelfItem`

  * 生成 `id`、`title`、`author`、`coverPath`（如有 `coverBytes` 则缓存，否则占位）、`filePath`、`isNovel=true`、`importTime`、`creationTime`

* 导航来源：`ViewerScreen` 在跳转到 `NovelReaderScreen` 时传入 `sourceFilePath:_selectedFile?.path` 与 `coverBytes:_previewImage`。

## 中文编码与文本显示

* 阅读页接收已按 `utf8.decode`（含必要回退）生成的整本文本；显示使用 `SelectableText`，禁用交互选择。

* 保留下方固定水印：左下角 `MxEnc` 低对比度标签。

## 夜间模式实现

* 状态管理：新增 `ThemeProvider`（`ChangeNotifier`）与 `AppThemeService`（封装 SharedPreferences 持久化）。

  * 字段：`themeMode: ThemeMode`；方法：`toggleDarkMode(bool)`、`load()`、`save()`。

* 入口：`MaterialApp` 使用 `themeMode`（`light`/`dark`/`system`）；将现有 `ThemeData` 保持，补充 `darkTheme: ThemeData.dark(useMaterial3:true)`。

* 设置页集成：`lib/screens/my_profile_screen.dart` 中的夜间模式开关调用 `ThemeProvider.toggleDarkMode` 并持久化。

* 阅读页颜色：使用当前 `Theme.of(context)`；不再覆盖背景与文字颜色逻辑（仍保留字号/行距与夜间切换按钮，改为调用 Provider）。

## 关联更新

* `ViewerScreen`：

  * 小说分流：在解密后判断 `fileType==novel`，构造 `NovelReaderScreen` 参数并跳转。

  * 中文按 `utf8.decode` 解码，结构化 JSON 时拼章为正文。

* `NovelReaderScreen`：

  * 添加 AppBar 与保存逻辑（依赖 `StorageService`）。

  * 固定水印左下角；取消动态水印。

## 测试与验证

* 解密 `.novel.mxenc` → 自动进入小说阅读页 → 顶栏正常、中文无乱码、点击“保存到书架”后在书架页可见。

* 解密图片 → 仍进入图片预览。

* 设置页切换夜间模式 → 全局生效并持久化；重启后保留状态。

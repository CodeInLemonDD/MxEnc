## 路由与页面流程修复
- 调整解密流程：解密小说后先跳转到“小说详情页”，从详情页进入阅读页；图片仍跳转到图片预览页。
- 修复书架点击：小说 → 详情页；图片 → 预览页；缺失数据（封面、作者、标题）从头部 metadata 与正文解密补齐。
- 统一导航：`MaterialApp.routes` 与 `onGenerateRoute` 保证参数传递（文件路径、封面字节、标题作者）。

## 深色模式与主题色
- 全局主题：完善 `ThemeProvider` 与持久化（SharedPreferences），`MaterialApp(themeMode)` 生效；提供 `darkTheme: ThemeData.dark(useMaterial3:true)`。
- 统一颜色用法：替换硬编码 `Colors.*` 为 `Theme.of(context).colorScheme.*` 和 `textTheme.*`；移除 `.withOpacity` 的残留，统一为 `withValues(alpha: x)`。
- 主题色切换：在设置页接入 Provider 切换 SeedColor 并持久化；所有卡片、边框、分隔线、按钮状态遵循 colorScheme。

## 权限与设备序列号、应用锁
- 设备序列号：优先使用 Rust `generate_device_fingerprint()`；失败时回退到平台信息组合（device_info_plus）生成稳定 ID；无权限页复制 ID 按钮正常。
- 应用锁：实现 PIN 锁（SharedPreferences + 本地校验），应用启动/解锁关键页前拦截；支持夜间主题下的 UI。

## 书架、删除、回收站、日志
- 书架索引：完善本地 JSON 索引（id、type、title、author、coverPath、importedAt、createdAt、path）。
- 删除与回收站：书架项删除移入 `trash/` 并写入 `trash.json`；可还原与清理；支持小说与图片。
- 加密/解密日志：记录到 `encrypt_logs.json` / `decrypt_logs.json`；设置页展示最近 N 条并可清理。

## Android Release 构建与安装
- 清理与依赖：`flutter clean`、删除 `build/` 与插件缓存冲突、`flutter pub cache clean`、`flutter pub get`。

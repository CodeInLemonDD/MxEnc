## 总体架构

* 栈：Flutter（Material 3）+ Provider（状态）+ FRB v2 + Rust（AES-GCM + Argon2）

* 数据：本地文件索引（JSON/SQLite 简版）、封面缓存、加/解密日志、回收站、偏好设置（主题、夜间、应用锁）。

* 文件格式：升级 .mxenc 到 v2，头部包含类型与元数据，支持小说结构化信息与封面。

## 页面与交互

* 首页（MainPage）：

  * 顶部 logo；两个按钮：“我要加密”“我要解密”；底栏（首页、书架、我的）。

  * “我要加密”：先进行权限检查（设备指纹+授权），通过则进入加密类型选择页。

  * “我要解密”：进入解密页面。

* 无权限提示页（PermissionScreen）：

  * 显示哭脸表情包与提示文字；展示 QQ：1211239054；按钮“复制序列号”（设备指纹）。

* 加密入口页（EncryptEntry）：

  * 两个入口：“加密图片”“上传/编辑小说”。

* 图片加密页（EncryptImageScreen）：

  * 选择图片文件（jpg/png/webp 等）；输入密码；可选元数据（标题、作者、标签）；保存为 .mxenc。

* 小说上传/编辑页（NovelUploadScreen）：

  * 新建/导入小说工程：标题、作者、标签、分卷、章节列表、封面、创作时间；支持编辑文本，预览；导出为 .mxenc。

* 解密页（ViewerScreen）：

  * 星星眼表情包；选择 .mxenc；图片直接预览，小说展示封面；支持“保存到书架”。

* 书架页（BookshelfScreen）：

  * 网格（三列）；项包含封面+标题+作者；筛选排序（类型、导入时间、创作时间）；无数据提示。

  * 点击封面：图片 → ImagePreviewScreen；小说 → NovelDetailScreen。

* 小说详情页（NovelDetailScreen）：

  * 左侧封面；右侧作者、标签、分卷、章节数、字数；扁平菜单栏“目录/相关”；目录为章节列表进入阅读页；相关包含作者头像与简介。

* 小说阅读页（NovelReaderScreen）：

  * 主题色/夜间；字体大小、行距、页内目录；分页/章节切换；阅读进度与书签；安全相关（禁截屏/水印可选）。

* 我的页（MyProfileScreen）：

  * 回收站（删除项还原）；加密记录、解密记录（最近 N 项）；主题色与日/夜模式；应用锁（PIN/生物识别）；“用户群：xxxxx”。

## 权限与授权

* 设备序列号：Rust `generate_device_fingerprint()` 提供稳定 ID；Dart 端存储于 `shared_preferences`。

* 授权判断：

  * 卡密/白名单：本地保存授权列表（可后续接入后端）；或临时试用期；Novel/图片加密入口均需授权。

* 无权限提示页支持复制设备序列号到剪贴板。

## 文件格式与加密算法升级（.mxenc v2）

* 头部结构：

  * `MAGIC`（`MXENC20`）

  * `name_len` + `filename`

  * `file_type`（0:generic,1:image,2:novel,255:other）

  * `metadata_len` + `metadata_json`（UTF-8，小说含：title、author、tags、volumes、chapters、word\_count、created\_at）

  * `salt[32]`、`nonce[12]`、`ciphertext`

* 加密算法：AES-256-GCM；密钥派生：Argon2id（较强参数，考虑移动端性能平衡）；支持大文本小说按章节分块加密后整体封装。

* 图片封面：

  * 小说：封面（二进制）置于元数据或附加区；阅读时加载封面。

  * 图片类型：原图即内容；预览直接用解密结果。

## 数据存储与索引

* 书架索引：

  * 采用本地 JSON 存储（如 `app_data/bookshelf.json`），记录条目：id、type、title、author、cover\_path（缓存）、imported\_at、created\_at、path。

  * 封面缓存：`app_data/covers/<id>.jpg`；从解密内容或元数据生成。

* 日志：`encrypt_logs.json` / `decrypt_logs.json`（最近 N 条）。

* 回收站：移动到 `trash/` 并在索引标记；支持还原与清理。

* 偏好：主题、夜间、应用锁、群号等在 `shared_preferences`。

## 技术实现要点

* 路由：统一通过 `MaterialApp.routes` 与 `onGenerateRoute` 管理；首页按钮严格走权限检查。

* FRB 生成：固定 CLI 生成 Dart+Rust 绑定；避免手改生成文件；启动前完整重启，不用热重启。

* 图片加密修复：

  * 明确文件类型来源：图片页直接指定 `FileType.image`；Rust 端写入 `file_type` 与元数据；解密页以头部类型决定展示。

  * 验证 `ViewerScreen` 处理逻辑：图片直接 `Image.memory`；小说显示封面；错误处理与提示。

* 小说导出：

  * 编辑结构体转 JSON 元数据；章节内容拼装为统一明文或分块（先实现统一明文版本）；整体加密。

  * 导出后写入书架索引，生成封面缓存。

* 书架筛选：内存排序（type/imported\_at/created\_at），UI 下拉或弹窗；空态提示与导入入口。

* 安全：禁截屏（Windows/Android）、动态水印（设备 ID 可选），敏感日志不写明文。

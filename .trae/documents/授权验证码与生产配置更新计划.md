## 授权验证码（一次性卡密）
- 目标：在“卡密激活”页显示 4 位验证码（A-Z、a-z、0-9），用于绑定卡密的一次性使用。
- 展示与持久化：
  - 新增本地存储键 `activation_code`（SharedPreferences），首次进入生成并保存；之后读取显示，不允许手动刷新。
  - 仅在激活成功时自动刷新新的验证码并保存。
  - 切换页面或退出应用不刷新验证码。
- UI：在设备序列号区域下方增加“当前验证码：XXXX”的只读显示（`mxenc/lib/screens/permission_screen.dart`）。

## 授权校验变更（含验证码）
- License JSON 增加字段：`code`
  - 结构：`{ deviceId, exp, sig, code }`
- 签名口径更新：为避免被篡改，“sig = base64(HMAC-SHA256(secret, "deviceId|exp|code"))`。
- 本地校验逻辑（`mxenc/lib/utils/license_service.dart`）：
  - 解析 `deviceId/exp/sig/code`；取本地 `activation_code` 与 `code` 对比（严格相等）。
  - 计算期望签名并比对；有效期与设备一致且未过期。
  - 通过后按现有逻辑：标记授权，更新时间显示；成功时刷新验证码并保存。

## 时长累计与旧逻辑兼容
- 保持已实现的“累计时长”策略：在当前仍有效时，将新卡密剩余秒数加入 `bonusSeconds`，并保留有效期更长的卡密字符串；倒计时显示 `剩余 + bonusSeconds`。
- 与验证码联动：只有当前验证码对应的卡密可生效；成功后刷新验证码，避免重复使用旧卡密。

## license_tool.py 适配
- 生成 4 位验证码（A-Z、a-z、0-9）。
- 计算签名：`sig = base64.b64encode(HMAC_SHA256(secret, f"{deviceId}|{exp}|{code}")).decode('ascii')`
- 生成 `lic = { 'deviceId': device_id, 'exp': exp, 'sig': sig, 'code': code }`
- 输出 Base64URL 编码的 JSON 字符串，保持与客户端一致。

- 激活成功：

  - 刷新验证码并保存，授权页倒计时立即更新。
- 已授权用户打开授权页：显示绿色“已授权，可增加时长”，并展示当前验证码（用于追加时长）。

## 测试用例

# "物理分卷（大文件架）" 功能实现计划

## 1. 核心目标

实现基于**物理文件夹**的“系列/分卷”管理功能，解决长篇作品（如漫画、连载小说）的文件管理、阅读体验和安全分享问题。

## 2. 详细设计方案

### 2.1 数据结构与存储 (`StorageService`)

* **物理结构**：

  * 在 `app_data/files/` 下支持创建子文件夹。

  * 文件夹即为一个“系列 (Series)”。

  * 系列内包含：

    * `series.json`: 核心元数据（标题、封面引用、分卷列表、密码映射）。

    * `key.enc` (可选): 加密后的全系列密码库（用于分享解锁）。

    * `*.mxenc`: 实际的分卷加密文件。

    * `cover.jpg` (可选): 系列封面。

* **元数据定义 (`series.json`)**:

  ```json
  {
    "id": "uuid",
    "title": "系列标题",
    "author": "作者",
    "coverPath": "cover.jpg",
    "volumes": [
      { "id": "v1", "title": "第1卷", "filename": "vol1.mxenc" },
      { "id": "v2", "title": "第2卷", "filename": "vol2.mxenc" }
    ],
    "passwords": {
      "v1": "encoded_pwd_1", 
      "v2": "encoded_pwd_2"
    }
  }
  ```

* **API 变更**:

  * `StorageService.loadShelf()`: 需要递归扫描 `files/` 目录，识别文件夹为特殊 Item (`isSeries: true`)。

  * `StorageService.createSeries(String title)`: 创建新文件夹。

  * `StorageService.moveItemToSeries(String itemId, String seriesId)`: 移动文件并更新索引。

### 2.2 UI 交互层

* **书架页 (`BookshelfScreen`)**:

  * **显示**: 系列以文件夹图标或“堆叠封面”样式显示。

  * **操作**:

    * 右上角菜单 -> "新建文件夹"。

    * 长按项 -> "移动到..."。

    * 长按文件夹 -> "导出 (.mxzip)"。

* **系列详情页 (`SeriesDetailScreen`)** (新增):

  * 展示系列大封面、简介。

  * **分卷列表**:

    * 列出所有分卷。

    * 状态指示：🔒 (未解密/无密码)、🔓 (已存密码)。

  * **阅读逻辑**: 点击分卷 -> 调用 `ViewerScreen` (需适配传入密码)。

### 2.3 导入导出与安全 (`.mxzip`)

* **导出 (.mxzip)**:

  * **格式**: 标准 ZIP。

  * **流程**: 打包文件夹内容。

  * **安全**: 询问“设置提取码”。若设置，则将 `passwords` 字段加密为 `key.enc` 放入 ZIP，并从 `series.json` 中移除明文密码。

* **导入**:

  * 识别 `.mxzip` 后缀。

  * 解压到 `files/` 下的新文件夹。

  * 检测 `key.enc`:

    * 有 -> 弹窗输提取码 -> 解锁全部分卷。

    * 无 -> 仅导入，需逐个输密码。

## 3. 执行步骤 (Step-by-Step)

### Phase 1: 基础架构 (Data & Storage)

1. **定义模型**: 创建 `SeriesItem` 和 `VolumeItem` 模型类。
2. **改造 StorageService**:

   * 实现 `createSeriesFolder(String name)`。

   * 实现 `moveFileToSeries(String filePath, String seriesPath)`。

   * 修改 `loadShelf()` 以兼容文件夹扫描。

### Phase 2: 书架交互 (Bookshelf UI)

1. **新建文件夹功能**: UI 弹窗 + 调用 Service。
2. **文件归档功能**: 实现“长按 -> 移动到”交互逻辑。
3. **文件夹渲染**: 在 GridView 中区分显示文件夹 Item。

### Phase 3: 系列详情与阅读 (Series Detail)

1. **开发** **`SeriesDetailScreen`**:

   * 展示分卷列表。

   * 实现“添加分卷”（导入新文件到该文件夹）。
2. **连通阅读器**: 点击分卷自动尝试使用存储的密码解密并打开。

### Phase 4: 高级功能 (Import/Export)

1. **ZIP 打包**: 引入 `archive` 库实现文件夹打包。
2. **加密导出**: 实现 `key.enc` 的 AES 加密/解密逻辑。
3. **文件关联**: 注册 `.mxzip` 文件关联（Android/Windows）。

## 4. 注意事项

* **兼容性**: 必须保证旧版扁平文件结构依然能正常工作。

* **性能**: 扫描大文件夹时避免阻塞 UI，需使用 Isolate 或异步流。

* **路径处理**: 严防文件名冲突和路径遍历攻击。
